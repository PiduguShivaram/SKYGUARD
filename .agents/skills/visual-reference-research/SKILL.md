# Visual Reference Research Standards

## 1. Principles of Forensic Reference Analysis
1. **Look Beyond Surface Elements**: Do not stop at "there is a canvas" or "there is an animation". Deconstruct the underlying coordinate math, spring tension, layout ratios, light sources, and typographic hierarchy.
2. **Catalog Integrity**: Examine real production assets, frame rates, interaction curves, and state progressions.
3. **Extraction of Intent**: Identify *why* an interaction feels rewarding (e.g. spring overshoot giving physical mass to a slider) and translate that mathematical principle to the target domain.

## 2. Benchmark Breakdown
- **Valentime (Noomo)**: Atmospheric continuity, kinetic typography reveals, interactive depth planes, cinematic chapter pacing.
- **Igloo Inc**: Tactile elasticity, interactive cursor tracking, organic micro-bounces, responsive playfulness.
- **Santioni Spirits**: Dark sensory luxury, film-grain texture, extreme editorial typographic contrast, seamless virtual scroll momentum.
