# Visual Quality Assurance Standards

## 1. Independent Review Mandate
Visual QA must act as a strict critic, not a rubber stamp. A passing test suite or clean build is not proof of aesthetic quality.

## 2. Review Dimensions (The 100-Point Scorecard)
1. **Art Direction & Originality (20%)**: Does the interface feel like an original creative world, or does it look like a template?
2. **Composition & Typography (15%)**: Extreme scale contrast, deliberate whitespace, clear reading order.
3. **Motion Craftsmanship (15%)**: Organic spring physics, zero linear CSS stops, fluid choreography.
4. **Narrative Continuity (15%)**: Clear progression from Chapter 1 to Chapter 4 without jarring transitions.
5. **Meaningful Interaction (10%)**: Direct manipulation (scrubbing, magnetic pull, spotlight).
6. **Public Usability (10%)**: Core weather information instantly glanceable.
7. **Mobile Experience (5%)**: Touch ergonomics, zero horizontal overflow, fluid scaling.
8. **Accessibility (5%)**: WCAG contrast compliance, screen-reader landmarks, reduced-motion fallbacks.
9. **Performance (5%)**: Locked 60fps, low memory footprint, zero layout shifts (CLS < 0.1).
