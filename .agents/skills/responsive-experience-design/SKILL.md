# Responsive Experience Design Standards

## 1. Compositional Adaptation
- **Widescreen Desktop (1440px - 1920px)**: Cinematic narrative layout, expansive atmospheric canvas, side-by-side temporal timeline and world pulse radar.
- **Tablet (768px - 1024px)**: Balanced two-tier presentation, touch-optimized scrubber with generous target zones.
- **Mobile (360px - 390px)**: Vertical narrative flow, thumb-driven horizontal timeline carousel, bottom-sheet alert drawers.
